# ウィザード形式送信機能の実装完了

## 📋 実装概要

Phase 5のウィザードUI実装が完了しました。これで、勤務連絡を4ステップで簡単に送信できるようになりました。

## 🎯 実装内容

### 1. ウィザード画面 (`templates/wizard.html`)

#### ステップ1: 勤務日と勤務場所を選択
- 勤務日をカレンダーから選択
- 勤務場所をドロップダウンから選択
- デフォルトで本日の日付が設定される

#### ステップ2: アルバイトスタッフを選択
- アルバイト従業員のみが表示される（`/api/part_time_employees` APIを使用）
- カード形式で従業員を表示
- クリックで選択/解除が可能
- LINE登録済み/未登録のバッジ表示

#### ステップ3: 出勤時間を設定
- 各選択されたスタッフごとに時間設定
- 15分単位で時間を調整可能
- **+/- ボタン** で簡単に15分ずつ調整
- 時間表示は大きく見やすい（24px）
- デフォルトは9:00

#### ステップ4: 確認画面
- 送信内容を一覧表示
- 勤務日、勤務場所、各スタッフの出勤時間を確認
- 送信ボタンで一斉送信

### 2. UI/UX の特徴

- **プログレスバー**: 現在のステップを視覚的に表示
- **カード式選択**: 従業員選択が直感的
- **15分単位の時間調整**: +/- ボタンでワンタップ操作
- **戻るボタン**: 各ステップで前に戻れる
- **バリデーション**: 必須項目の入力チェック
- **レスポンシブデザイン**: Bootstrap 5でモバイル対応

## 🔧 技術詳細

### 時間調整機能の実装

```javascript
function adjustTime(empId, minutes) {
    const [hours, mins] = workTimes[empId].split(':').map(Number);
    let totalMinutes = hours * 60 + mins + minutes;

    // 0-23:45の範囲内に制限
    if (totalMinutes < 0) totalMinutes = 0;
    if (totalMinutes >= 24 * 60) totalMinutes = 23 * 45;

    const newHours = Math.floor(totalMinutes / 60);
    const newMins = totalMinutes % 60;

    workTimes[empId] = `${String(newHours).padStart(2, '0')}:${String(newMins).padStart(2, '0')}`;
    document.getElementById(`time_${empId}`).textContent = workTimes[empId];
}
```

## 🎨 UI改善点

### 従来の送信画面（index.html）
- 全従業員を一覧表示
- 個別に日付・場所・時間を設定
- 共通設定を適用する必要あり
- **→ 多くの従業員に送る場合は手間**

### 新しいウィザード画面（wizard.html）
- ステップごとに進行
- アルバイトのみ表示
- 共通の日付・場所を最初に設定
- 時間だけ個別調整
- **→ 直感的で操作が簡単**
